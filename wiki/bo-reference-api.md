# BO Reference API

Интеграция со справочником бизнес-объектов. **11 методов**.

**Базовый путь**: `/api/v4/BoReference`

## Основные DTO

- `BusinessObjectDto` - бизнес-объект
- `BoVersionDto` - версия бизнес-объекта

См. [[types-reference.md]]

---

## Получение информации

### Бизнес-объекты

| Метод | Путь | Описание |
|-------|------|----------|
| GET | `/preview-bo-object` | Предпросмотр бизнес-объекта |
| GET | `/preview-bo-object-for-version` | Предпросмотр бизнес-объекта для версии |
| GET | `/preview-bo-object-from-polynom` | Предпросмотр бизнес-объекта из полинома |
| GET | `/get-bo-versions` | Получить версии бизнес-объекта |

### Атрибуты

| Метод | Путь | Описание |
|-------|------|----------|
| GET | `/get-independent-attribute` | Получить независимый атрибут |
| GET | `/get-independent-link-attribute` | Получить независимый атрибут связи |

### Единицы измерения

| Метод | Путь | Описание |
|-------|------|----------|
| GET | `/get-m-unit-list` | Получить список единиц измерения |

# Files API

Файлы, загрузка, скачивание, архивы. **76 методов**.

## Области API

- `/api/v4/File` - файлы
- `/api/v4/downloads` - скачивание
- `/api/v4/uploads` - загрузка
- `/api/v4/DigitalSignature` - цифровая подпись

## Основные DTO

- `FileDto` - файл
- `ArchiveDto` - архив
- `FileSignatureDto` - подпись файла
- `ArchiveComponentDto` - компонент архива

См. [[types-reference.md]]

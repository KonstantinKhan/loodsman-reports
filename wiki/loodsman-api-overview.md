## Обзор архитектуры

Loodsman Web API предоставляет REST-интерфейс для работы с системой управления инженерными данными и бизнес-процессами. API содержит более 12,900 DTO-типов, организованных в следующие основные категории:

### Категории API

| Категория | Количество DTO | Описание |
|-----------|---------------|----------|
| Attributes | 444 | Атрибуты объектов, значения, шаблоны |
| Links | 253 | Связи между объектами, типы связей |
| Objects and Versions | 262 | Объекты, версии, бизнес-объекты |
| Workflow and Processes | 184 | Маршруты, этапы, бизнес-процессы |
| Tasks | 255 | Задачи, состояния, мультитаски |
| Reports | 52 | Отчёты, параметры, форматы экспорта |
| Files and Archives | 196 | Файлы, архивы, подписи |
| Authorization and Users | 339 | Авторизация, роли, пользователи |
| Search and Filter | 24 | Поиск, фильтры, операторы |
| Effectivity | 50 | Действительность, правила |
| Configuration | 89 | Конфигурации, шаблоны, скрипты |

## Основные концепции

### Объекты (Objects)
- **Object** - базовая сущность в системе (документ, изделие, узел и т.д.)
- **Version** - версия объекта с состоянием и атрибутами
- **Type** - тип объекта определяет его структуру и поведение

### Связи (Links)
- **Link** - связь между двумя объектами (родитель-потомок)
- **AbsLink** - абстрактная связь для ссылок между объектами
- **LinkEntry** - конкретное вхождение объекта в связь

### Workflow
- **Route** - маршрут согласования объекта
- **Stage** - этап маршрута
- **Task** - задача для исполнителя на этапе

### Атрибуты (Attributes)
- **Attribute** - именованное свойство объекта
- **AttributeValue** - значение атрибута для конкретного объекта
- **AttributeTemplate** - шаблон атрибута для типа

## Авторизация

API использует API key авторизацию через HTTP-заголовок:

```
Authorization: <api_key>
```

## Типы данных

API поддерживает следующие типы данных:

### Примитивные типы
- `str` - строка
- `int` - целое число
- `float` - число с плавающей точкой
- `bool` - булево значение
- `datetime` - дата и время
- `date` - дата

### Коллекции
- `[int]` - массив целых чисел
- `[str]` - массив строк
- `[any]` - массив любого типа

### Специальные типы
- `file` - файл для загрузки
- `FilePath` - путь к файлу
- `Crc32` - контрольная сумма CRC32

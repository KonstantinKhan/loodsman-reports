# Authentication API

Аутентификация, сессии. **44 метода**.

## Области API

- `/api/v4/Auth` - аутентификация
- `/api/v4/SSO` - SSO (Single Sign-On)

## Основные DTO

- `AuthUserDto` - авторизованный пользователь
- `SessionDto` - сессия

См. [[types-reference.md]]

---

## Аутентификация (Auth)

### Вход и выход

| Метод | Путь | Описание |
|-------|------|----------|
| POST | `/api/v4/Auth/login` | Вход в систему |
| POST | `/api/v4/Auth/logout` | Выход из системы |

### Сессии

| Метод | Путь | Описание |
|-------|------|----------|
| POST | `/api/v4/Auth/clone-session` | Клонировать сессию |

### Имперсонация

| Метод | Путь | Описание |
|-------|------|----------|
| POST | `/api/v4/Auth/impersonate` | Имперсонализация (войти от имени другого пользователя) |

### Текущий пользователь

| Метод | Путь | Описание |
|-------|------|----------|
| GET | `/api/v4/Auth/current-user` | Получить текущего пользователя |
| GET | `/api/v4/Auth/is-admin` | Проверить, является ли пользователь администратором |

### Базы данных

| Метод | Путь | Описание |
|-------|------|----------|
| GET | `/api/v4/Auth/databases` | Получить список баз данных |

## Авторизация

API использует API key авторизацию через HTTP-заголовок:

```
Authorization: <api_key>
```

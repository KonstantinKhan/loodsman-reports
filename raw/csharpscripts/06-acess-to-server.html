Подключение к СП (HttpClient)

Для взаимодействия с WebAPI сервера приложений можно использовать стандартный HttpClient. (https://learn.microsoft.com/ru-ru/dotnet/fundamentals/networking/http/httpclient)

Для построения данного отчета потребуется обращение к 4 конечным точкам WebAPI: Создадим отдельный класс «LoodsmanApiClient» с методами для запроса информации:

Сделаем класс публичным и добавим в него HttpClient и созданный нами AppConfigurations.
Будет использован подход с manual depency passing, он имеет в себе все плюсы внедрения зависимостей, кроме управления жизненным циклом: (https://learn.microsoft.com/ru-ru/dotnet/core/extensions/dependency-injection/overview)

Добавим инициализацию класса:
(https://learn.microsoft.com/ru-ru/dotnet/csharp/programming-guide/classes-and-structs/object-and-collection-initializers)

Здесь конфигурация приходит «извне», а транспорт в виде http-клиента конструируется при инициализации.
Разберем настройки http-клиента: 

_httpClient = new HttpClient
{
    BaseAddress = new Uri($"{_config.AppServerHost}/api/v{_config.ApiVersion}/"),
    Timeout = TimeSpan.FromSeconds(_config.RequestTimeoutSeconds)
};
_httpClient.DefaultRequestHeaders.Add("web-loodsman-session", _config.SessionId);
BaseAddress – базовый адрес, куда будут идти все запросы. Удобно задать сразу, чтобы не писать в каждом запросе. Timeout – ограничение времени запроса. Базовый адрес собирается из составляющих через подход интерполяции строковых данных.
(https://learn.microsoft.com/ru-ru/dotnet/csharp/tutorials/string-interpolation)
Последняя строка – этого конфигурирование HTTP заголовка
(https://learn.microsoft.com/ru-ru/dotnet/fundamentals/networking/http/httpclient#create-an-httpclient-object)
Для сервера приложений ЛОЦМАН:PLM предусмотрен служебный заголовок web-loodsman-session, который позволяет передать идентификатор сессии, для получения данных. В него передаем значение идентификатора сессии sessionId, полученного скриптом из параметров командной строки (получение этих параметров описано в этом разделе)

Можно заметить, что таймаут запроса берется не из переданных параметров, а из строго-заданного поля RequestTimeoutSeconds. Длительности в 60 секунд хватит для получения данных для любой из перечисленных выше конечных точек, и это гарантирует, что запрос и приложение не будет висеть слишком долго.

Теперь у нас есть все необходимые настройки для обращения к конечным точкам, и http-клиент, отвечающий за транспорт запросов и ответов. Можно приступать к написанию методов запроса информации.

В первую очередь создадим асинхронный метод для получения информации о корневом объекте. (https://learn.microsoft.com/ru-ru/dotnet/csharp/asynchronous-programming/)

Возвращаемым типом метода будет List, описанным в Models.cs:

Здесь мы используем http-клиент для выполнения GET-запроса с предопределенным возвращаемым типом. Конечная точка, к которой мы обращаемся была сохранена нами на этапе работы со Swagger (описано в этом разделе):

Красным выделен "собранный" нами на этапе инициализации BaseAddress, синим – конечная точка для получения информации. В Swagger мы проверяли работу метода с idVersion=1012, в коде idVersion формируется динамически из входных пользовательских данных.

Добавим в метод обработку исключений (https://learn.microsoft.com/ru-ru/dotnet/csharp/fundamentals/exceptions/) 

public async Task<List<ObjectInfo>> GetObjectInfoAsync(int idVersion)
{
    try
    {
        var result = await _httpClient.GetFromJsonAsync<List<ObjectInfo>>(
            $"ObjectInfo/get-prop-objects?objectList={idVersion}");

        return result ?? new List<ObjectInfo>();
    }
    catch (HttpRequestException ex)
    {
        throw new InvalidOperationException(
            $"Ошибка при получении информации об объекте {idVersion}", ex);
    }
    catch (TaskCanceledException ex)
    {
        throw new TimeoutException(
            $"Превышено время ожидания при получении информации об объекте {idVersion}", ex);
    }
}
Далее сделаем по такому же принципу оставшиеся три метода. Они будут отличаться только конечной точкой запроса, а два из них - выходным типом данных.

Последнее, но не обязательное, что нужно добавить – это использование интерфейса IDisposable и его реализацию методом Dispose (https://learn.microsoft.com/ru-ru/dotnet/fundamentals/runtime-libraries/system-idisposable) 

public class LoodsmanApiClient
заменим на 
public class LoodsmanApiClient : IDisposable
и добавим метод высвобождения ресурсов: 
public void Dispose()
{
 _httpClient?.Dispose()
}

Финальный код класса LoodsmanApiClient.cs 

using System.Net.Http.Json;

namespace ExactProductStructureReport
{
    public class LoodsmanApiClient : IDisposable
    {
        private readonly HttpClient _httpClient;
        private readonly AppConfigurations _config;
        public LoodsmanApiClient(AppConfigurations config)
        {
            _config = config ?? throw new ArgumentNullException(nameof(config));

            _httpClient = new HttpClient
            {
                BaseAddress = new Uri($"{_config.AppServerHost}/api/v{_config.ApiVersion}/"),
                Timeout = TimeSpan.FromSeconds(_config.RequestTimeoutSeconds)
            };

            _httpClient.DefaultRequestHeaders.Add("web-loodsman-session", _config.SessionId);
        }

        public async Task<List<ObjectInfo>> GetObjectInfoAsync(int idVersion)
        {
            try
            {
                var result = await _httpClient.GetFromJsonAsync<List<ObjectInfo>>(
                    $"ObjectInfo/get-prop-objects?objectList={idVersion}");

                return result ?? new List<ObjectInfo>();
            }
            catch (HttpRequestException ex)
            {
                throw new InvalidOperationException(
                    $"Ошибка при получении информации об объекте {idVersion}", ex);
            }
            catch (TaskCanceledException ex)
            {
                throw new TimeoutException(
                    $"Превышено время ожидания при получении информации об объекте {idVersion}", ex);
            }
        }
        public async Task<List<ObjectInfo>> GetLinkedObjectsAsync(int idVersion, string linkType)
        {
            try
            {
                var result = await _httpClient.GetFromJsonAsync<List<ObjectInfo>>(
                    $"ObjectInfo/get-linked-fast?idVersion={idVersion}&linkType={linkType}");

                return result ?? new List<ObjectInfo>();
            }
            catch (HttpRequestException ex)
            {
                throw new InvalidOperationException(
                    $"Ошибка при получении связанных объектов для версии {idVersion}", ex);
            }
            catch (TaskCanceledException ex)
            {
                throw new TimeoutException(
                    $"Превышено время ожидания при получении связанных объектов для версии {idVersion}", ex);
            }
        }

        public async Task<List<Attributes>> GetVersionAttributesAsync(int idVersion)
        {
            try
            {
                var result = await _httpClient.GetFromJsonAsync<List<Attributes>>(
                    $"ObjectInfo/get-info-about-version-mode-3?idVersion={idVersion}");

                return result ?? new List<Attributes>();
            }
            catch (HttpRequestException ex)
            {
                throw new InvalidOperationException(
                    $"Ошибка при получении атрибутов версии {idVersion}", ex);
            }
            catch (TaskCanceledException ex)
            {
                throw new TimeoutException(
                    $"Превышено время ожидания при получении атрибутов версии {idVersion}", ex);
            }
        }

        public async Task<List<Attributes>> GetLinkAttributesAsync(int idLink)
        {
            try
            {
                var result = await _httpClient.GetFromJsonAsync<List<Attributes>>(
                    $"ObjectInfo/get-link-attributes-2?idLink={idLink}&mode=0");

                return result ?? new List<Attributes>();
            }
            catch (HttpRequestException ex)
            {
                throw new InvalidOperationException(
                    $"Ошибка при получении атрибутов связи {idLink}", ex);
            }
            catch (TaskCanceledException ex)
            {
                throw new TimeoutException(
                    $"Превышено время ожидания при получении атрибутов связи {idLink}", ex);
            }
        }

        public void Dispose()
        {
            _httpClient?.Dispose();
        }

    }
}

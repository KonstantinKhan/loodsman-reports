Добавление глобальных настроек

Удобной практикой считается создавать классы с глобальными настройками, чтобы потом использовать их в любом участке кода.

Это позволяет:

  • Иметь единую точку истины для какой-либо инфраструктурной части, которая должна быть неизменяема на протяжении всей работы программы.
  • Настроить код один раз в одном месте.
  • Если в будущем окажется необходимым изменить какую-то часть такого инфраструктурного кода, то это можно будет сделать только в одном месте.

Под такую инфраструктурную задачу идеально подходит конфигурация настроек форматирования JSON.

Создадим статический класс Global.cs:

Добавим в него настройки форматирования JSON:

Теперь для сериализации и десериализации JSON в любом месте нашего кода мы можем указать настройки форматирования JSON через Global.JsonSerializerOptions.

Описание настроек форматирования JSON

  • WriteIndented = true
    • Форматирует JSON с отступами и переносами строк для удобного чтения человеком.
    • Без этого JSON будет в одну строку.
  • PropertyNameCaseInsensitive = true
    • Делает десериализацию нечувствительной к регистру имён свойств.
    • Например, можно десериализовать {"Name": "..."} в свойство name.
  • PropertyNamingPolicy = JsonNamingPolicy.CamelCase
    • Автоматически преобразует имена свойств C# в camelCase при сериализации.
    • Например, свойство FirstName станет firstName.
  • Encoder = JavaScriptEncoder.UnsafeRelaxedJsonEscaping
    • Ослабляет экранирование символов в JSON:
      • Не экранирует ASCII символы (кроме обязательных:  "  \  \b  \f  \n  \r  \t  )
      • Сохраняет кириллицу и Unicode символы как есть, без \uXXXX
      • Полезно для читаемости и сокращения размера JSON

Полный код класса глобальных настроек: 

using System.Text.Encodings.Web;
using System.Text.Json;

namespace ExactDocumentFilesReport
{
    public static class Global
    {
        public static readonly JsonSerializerOptions JsonSerializerOptions = new()
        {
            WriteIndented = true,

            PropertyNameCaseInsensitive = true,

            PropertyNamingPolicy = JsonNamingPolicy.CamelCase,

            Encoder = JavaScriptEncoder.UnsafeRelaxedJsonEscaping
        };
    }
}

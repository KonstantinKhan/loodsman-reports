# Коды ошибок

Loodsman API использует стандартный формат ответов с ошибками.

## Формат ответа с ошибкой

```json
{
  "errorCode": "string or int",
  "errorMessage": "Описание ошибки",
  "timeGeneratedUtc": "2024-01-01T10:30:00Z"
}
```

## Общие коды ошибок

### Успешное выполнение

- `0` или `null` - Операция выполнена успешно

### Ошибки авторизации

- `401` - Не авторизован
- `403` - Доступ запрещён

### Ошибки клиента

- `400` - Неверный запрос
- `404` - Ресурс не найден
- `409` - Конфликт данных

### Ошибки сервера

- `500` - Внутренняя ошибка сервера

## Обработка ошибок

### Рекомендации

1. Всегда проверяйте `errorCode` и `errorMessage` в ответе
2. При `errorCode != 0` или `null` считайте операцию неудачной
3. Логируйте `errorMessage` для отладки
4. Обрабатывайте известные коды ошибок соответствующим образом
5. Для неизвестных ошибок показывайте `errorMessage` пользователю

### Пример обработки

```javascript
const response = await fetch('/api/v4/ObjectInfo/get-info-about-version', {
  headers: {
    'Authorization': apiKey
  }
});

const data = await response.json();

if (data.errorCode && data.errorCode !== '0') {
  console.error('Error:', data.errorMessage);
  // Обработка ошибки
} else {
  // Успешное выполнение
  const version = data.result;
}
```

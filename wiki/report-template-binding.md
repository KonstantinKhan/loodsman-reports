# Привязка результатов выполнения скрипта к шаблону

После разработки скрипта отбора данных необходимо привязать полученную структуру данных к шаблону оформления отчёта.

## Как создать отчёт и загрузить в него скрипт (рекомендуемый порядок)

Служба выполнения скриптов — отдельный компонент серверной части ЛОЦМАН:PLM (настраивается в "Центре Управления Комплексом"). Отчёт как сущность в базе данных ссылается на скрипт отбора данных (в службе выполнения скриптов) и на шаблон оформления (FastReport, в каталоге общих данных).

Рекомендуемый порядок разработки:

1. **Создать новый отчёт в веб-приложении "ЛОЦМАН-Конфигуратор".** При создании отчёта конфигуратор автоматически создаёт **и** новый скрипт отбора данных (уже зарегистрированный в службе выполнения скриптов, с уже заполненными полями архива/файла запуска), **и** новый пустой шаблон.
2. Разработать скрипт одним из двух способов:
   - прямо в редакторе, встроенном в веб-приложение "ЛОЦМАН-Конфигуратор";
   - **во внешней среде разработки** (Visual Studio, VS Code) — в этом случае сначала нужно **выгрузить (скачать) файлы уже созданного на шаге 1 скрипта** из веб-редактора и использовать их как стартовый шаблон/каркас проекта (там уже верное имя проекта, структура архива и настройка «файла запуска», которые ожидает конфигуратор). Свой код (`AppConfiguration.cs`, `LoodsmanApiClient.cs`, `Models.cs`, `ReportService.cs`, `ReportPrinter.cs`, `Program.cs`) нужно поместить в этот же каркас, сохранив имя проекта/сборки, которое конфигуратор сгенерировал на шаге 1.
   - по завершении разработки — упаковать проект в zip-архив и загрузить обратно в редактор скрипта командой загрузки с диска.
3. Выполнить скрипт в веб-приложении "ЛОЦМАН-Конфигуратор" и получить набор данных для оформления отчёта (тестовые данные — это нормально, важна лишь итоговая структура JSON).
4. Перейти к редактированию шаблона в "ЛОЦМАН-Конфигураторе" — конфигуратор привязывает полученный на шаге 3 JSON как источник данных для шаблона.
5. Провести разметку шаблона. При необходимости управлять оформлением средствами **FastReport.NET** (документация — на сайте производителя).

> **Важно**: точный формат полей «архив скрипта» / «файл запуска» в диалоге загрузки скрипта в этих исходных материалах не описан детально — единственный документированный совет (`raw/scripting.html`): при внешней разработке отталкиваться от файлов, которые конфигуратор сам сгенерировал на шаге 1, а не собирать архив с нуля вручную. Если после этого поля всё ещё не совпадают — уточнить у администратора ЛОЦМАН:PLM точный ожидаемый формат.

## Дальнейшая работа с шаблоном

- Предварительный просмотр сформированного по шаблону отчёта доступен в редакторе шаблона по команде главного меню «Просмотр».
- В приложении "ЛОЦМАН-Конфигуратор" можно запустить отчёт на формирование командной кнопкой «Сформировать отчёт». После указания параметров отчёта и выходного формата документ будет сформирован и загружен в браузер.
- Поддерживаемые форматы вывода: файл FastReport, Microsoft Word, Microsoft Excel, LibreOffice Writer/Calc, PDF, HTML, PNG.

# Reports API

Отчёты, скрипты, экспорт. **98 методов**.

## Области API

- `/api/v4/Report` - отчёты
- `/api/v4/GlobalReportService` - глобальная служба отчётов
- `/api/v4/ServerReports` - серверные отчёты

## Основные DTO

- `ReportDto` - отчёт
- `ReportParameterDto` - параметр отчёта
- `ReportItemDto` - элемент отчёта

См. [[types-reference.md]]

## Параметры отчётов

### Типы параметров

- `0` - строка
- `1` - число
- `2` - дата
- `3` - логическое значение
- `4` - список
- `5` - пользователь
- `6` - объект
- `7` - версия объекта

### Типы управления вводом

- `0` - текстовое поле
- `1` - числовое поле
- `2` - дата
- `3` - чекбокс

### Форматы экспорта

- `1` - PDF
- `2` - Excel
- `3` - Word
- `4` - HTML
- `5` - CSV
- `6` - RTF
- `7` - XML
- `8` - Image

Подготовка инфраструктуры маппинга модели данных

Подготовка инфраструктуры маппинга модели данных Ранее, мы подключили две библиотеки для маппинга модели данных - Ascon.Plm.DataPacket и Ascon.Plm.Mapping.

Теперь необходимо создать класс, который инкапсулирует в себе логику преобразования данных из вызовов Server API (данные приходят в виде object) в модель данных.
Для этого создадим статический класс Mapper.cs:

Теперь создадим приватный статический метод CreateReader для создания реализации интерфейса IDataReader, который позволяет напрямую читать данные и преобразовать их в DataTable:

  • https://learn.microsoft.com/ru-ru/dotnet/api/system.data.idatareader?view=net-9.0
  • https://learn.microsoft.com/ru-ru/dotnet/api/system.data.datatable?view=net-8.0

При этом стоит отметить, что на самом деле вызовы на сервер приложений ЛОЦМАН:PLM через Server API возвращают не object, а массив байт byte[].
Возврат object вызван ограничениями работы COM-интерфейса для клиентских приложений ЛОЦМАН:PLM (написаны на языке программирования Delphi), так как изначально Server API разрабатывался именно для них.

Теперь создадим удобные методы-обёртки, которые позволяют преобразовать данные от Server API в указанный класс модели данных:

В данном случае, мы использовали встроенные методы класса DbMapper из библиотеки Ascon.Plm.Mapping, которые работают так:

  • FirstOrDefault (дословно "Первый или по умолчанию"):
    • Если данные от Server API пустые, то возвращает значение по умолчанию. Для класса - это null.
    • Если данные от Server API содержат один или более элемент, то возвращает первый элемент из списка.
  • ToList (дословно "Преобразовать в список") - возвращает набор данных независимо от того пустые данные от Server API или нет.

Общий код инфраструктуры маппинга модели данных:

using Ascon.Plm.DataPacket;
using Ascon.Plm.Mapping;

namespace ExactDocumentFilesReport
{
    public static class Mapper
    {
        private static DataPacketReader CreateReader(object data)
        {
            if (data is byte[] bytes)
            {
                return new DataPacketReader(bytes);
            }
            else
            {
                throw new ArgumentException($"Аргумент {nameof(data)} должен быть массивом байт", nameof(data));
            }
        }

        public static T FirstOrDefault<T>(object data) where T : class
        {
            using var reader = CreateReader(data);

            return DbMapper.FirstOrDefault<T>(reader);
        }

        public static List<T> ToList<T>(object data) where T : class
        {
            using var reader = CreateReader(data);

            return DbMapper.ToList<T>(reader);
        }
    }
}

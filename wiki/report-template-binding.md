# Привязка результатов выполнения скрипта к шаблону

После разработки скрипта отбора данных необходимо привязать полученную структуру данных к шаблону оформления отчёта.

> **Внимание**. Если скрипт разрабатывался во внешней среде разработки (Visual Studio, VS Code и т.п.), его нужно загрузить в службу выполнения скриптов в "ЛОЦМАН-Конфигураторе": открыть скрипт на редактирование и вызвать команду загрузки скрипта с диска. Скрипт должен быть предварительно упакован в zip-архив.

## Порядок работы

1. Редактирование шаблонов серверных отчётов выполняется в веб-приложении "ЛОЦМАН-Конфигуратор". Перед редактированием шаблона обязательно нужно выполнить скрипт и получить результирующий набор данных — данные могут быть тестовыми, главное получить конечную структуру JSON.
2. После выполнения скрипта "ЛОЦМАН-Конфигуратор" привязывает полученный набор данных к шаблону в качестве источника.
3. Провести разметку шаблона. При необходимости управлять оформлением отчёта средствами **FastReport.NET** (документация — на сайте производителя).
4. Предварительный просмотр сформированного по шаблону отчёта доступен в редакторе шаблона по команде главного меню «Просмотр».
5. В приложении "ЛОЦМАН-Конфигуратор" можно запустить отчёт на формирование командной кнопкой «Сформировать отчёт». После указания параметров отчёта и выходного формата документ будет сформирован и загружен в браузер.

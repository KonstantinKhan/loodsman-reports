# Search API

Поиск, фильтрация, навигация. **156 методов**.

## Области API

- `/api/v4/ObjectSearch` - поиск объектов
- `/api/v4/SecondaryView` - дополнительные представления
- `/api/v4/secondary-view` - вторичные представления

## Основные DTO

- `SearchFilterDto` - фильтр поиска
- `StringFilter` - строковый фильтр
- `NumericFilter` - числовой фильтр
- `DateFilter` - фильтр по дате
- `AndExpression` - логическое И
- `OrExpression` - логическое ИЛИ

См. [[types-reference.md]]

## Операторы фильтрации

### Строковые операторы

- `0` - равенство
- `1` - содержит
- `2` - начинается с
- `3` - заканчивается на
- `4` - не содержит

### Числовые операторы

- `0` - равенство
- `1` - больше
- `2` - меньше
- `3` - больше или равно
- `4` - меньше или равно
- `5` - не равно

### Операторы даты

- `0` - равенство
- `1` - больше
- `2` - меньше
- `3` - больше или равно
- `4` - меньше или равно
- `5` - не равно

### Логические операторы

- `0` - равенство

### Enum операторы

- `0` - равенство
- `1` - не равно
